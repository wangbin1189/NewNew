# NewNew Kids Website

Responsive static website for NewNew, operated by Tree New Bee LLC.

## Files

- `index.html`
- `styles.css`
- `script.js`

## Deploy to Cloudflare Pages

1. Push these files to the root of your GitHub repository.
2. In Cloudflare, go to **Workers & Pages**.
3. Create a Pages project and connect the GitHub repository.
4. For a plain static site:
   - Framework preset: **None**
   - Build command: leave blank
   - Build output directory: `/`
5. Deploy.
6. Add custom domains:
   - `newnewkids.com`
   - `www.newnewkids.com`

## Important

Do not commit SMTP keys, API keys, passwords, `.env` files, or private family/child information to a public repository.
